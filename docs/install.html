Install Vett for your browser

Takes about 60 seconds. Works on Chrome, Edge, and Brave.
⬇️ Download Vett (.zip)
Then follow the 5 steps below. You only do this once.
1

Unzip the file

Find vett_extension.zip in your Downloads, right-click it, and choose Extract All (Windows) or double-click it (Mac). Remember where the folder lands.

2

Open your extensions page

In your browser's address bar, type chrome://extensions and press Enter. (On Edge use edge://extensions, on Brave brave://extensions.)

3

Turn on Developer mode

Flip the Developer mode switch in the top-right corner of that page.

4

Load it

Click Load unpacked (top-left), then select the folder you unzipped in step 1.

5

Pin it & use it

Click the puzzle-piece 🧩 icon near your address bar and pin Vett. Click the Vett icon anytime to check, compare, or watch a wallet.

Is this safe? Yes — the extension has no login and sends nothing anywhere. It only reads Hyperliquid's public data in your browser.

Why the extra steps? Skipping the Chrome Web Store review means you install it directly. It's the same thing, just without the store.
